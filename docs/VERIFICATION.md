## 보관과 운영 상태

화면과 실행 링크를 공개 자료로 보관했다. 운영 DB·설정·인증 파일 백업은 별도 비공개 경로에 보관하고 원격/로컬 SHA-256 일치를 확인했다. 복원 리허설은 이번 자료 정리 과정에서 수행하지 않았다.

2026-10-22 자료와 비공개 백업 확보 후 EC2를 종료했다. AWS에서 terminated 상태, 공인 IP 없음, 서울 리전의 EBS 볼륨·탄력적 IP·자체 스냅샷 각 0개를 확인했다. 서비스는 오프라인이며 과거 서비스 주소를 현재 접속 가능한 데모 링크로 사용하지 않는다. 소스 코드, 실행 절차, 이미지와 검증 기록은 보관한다. DuckDNS의 IPv4 값은 0.0.0.0으로 변경해 반환된 서버 IP와의 연결을 해제했고 도메인 이름은 유지했다.
